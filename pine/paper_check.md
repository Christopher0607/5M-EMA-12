# 模拟盘验收清单

**在这张表填满并全部通过之前，不要把「Arm live orders」打开接到真实考核账户。**

脚本默认 `Arm live orders = OFF`。关闭状态下图表照常回测、照常画图，只是**不发出入场 alert**。
这是故意的默认值。

### 通过标准

| 项目 | 标准 | 不达标怎么办 |
|---|---|---|
| **方向** | **10/10 完全一致** | ❌ **立刻停止**。这是配置错误，不是滑点。回到 0.3 检查盘前盘后 |
| 手数 | 10/10 一致 | 检查点值参数和手数上限 |
| 入场价 | 差 ≤ 2 跳 | 差更多说明 alert 延迟或桥接慢，考虑换桥接商 |
| 止损单 | 10/10 存在 | ❌ 停止。见 1.5 |
| 15:35 平仓 | 10/10 触发 | 检查时区和 alert 是否设成「策略」而不是单个信号 |

**方向只要错一天就停。** 滑点是可以接受的成本，方向错是配置错误——它意味着你在跑一个
和回测不同的策略，之前所有的数字都不适用。

## 3. 上真实账户

前两步全绿之后：

1. 先上**最小档位**（Lucid $50K，不是 $150K）。回测显示 3/4 的平台上小账户反而更优。
2. `Arm live orders` 打开。
3. 建议同时设 `Stop after N consecutive losing days = 5`。按最优组合 34% 的通过率，
   连亏 5 天的概率约 12.5%——超过就该怀疑当前市场状态和回测假设不符了。
4. 前 20 个交易日继续每天对账，只是不用再填表。

---

## 4. 什么时候该停

- 连续 5 次考核没过
- 实盘回撤超过回测同期水平的 1.5 倍
- 任何一天方向和脚本图上的箭头不一致
