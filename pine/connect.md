# 接入路径 · 每一步的成本和作用

**先说一件可能改变你判断的事：propfirm 的考核账户本身就是模拟盘。**

你在考核阶段亏掉的是虚拟资金，真正付出的只有考核费。真金白银只在**通过考核、拿到资金账户
之后**才涉及。所以「paper trading」和「买一个考核」在这里几乎是同一件事，成本约 $45。

---

## 第 0 步 · 完全免费，不需要任何账户

**目的：确认脚本产生的信号和回测一致。配置错了，后面每一步都白搭。**

1. TradingView 加载脚本，图表设成 `MNQ1!` / 5 分钟 / **盘前盘后开启**
2. 生成对照数据：
   ```bash
   ./.venv/bin/python scripts/export_tv_check.py --since 2025 --max-contracts 40
   ```
3. 打开策略测试器 → 成交列表，和 `results/tv_expected_trades.csv` 逐日核对**日期 + 方向**

**通过标准**：方向 100% 一致。价格差几个跳正常（数据源和成交假设不同），**方向错就是配置错**。

> 这一步你已经做过一次并且对上了。脚本改了之后建议再扫一眼——这次改的是配色和字符串拼接，
> 不碰信号逻辑，理论上结果应该完全一样。

---

## 第 1 步 · 约 $45 · 买 Lucid $50K（LucidPro）

### 为什么是 Lucid，为什么是 $50K

两个独立的发现在这里收敛：

| 理由 | 数据 |
|---|---|
| **唯一两个阶段都允许自动化** | Apex 资金账户禁止 bot；TPT 全面禁止 |
| 原生支持 TradingView | 官方列为一级平台 |
| 中位成绩四家最高 | $20,623（Apex 天花板更高但自动化用不了） |
| 规则最宽容 | 日亏是**软性**违规（当天停手，不爆仓） |
| **$50K 优于 $150K** | $48,950 vs $27,717。利润目标随档位放大 3 倍，回撤上限只放大约 2 倍 |

### 买哪个

- 平台：**Lucid Trading**
- 产品：**LucidPro**（不是 Flex / Direct / Daily）
- 档位：**$50K**
- 关键参数：目标 $3,000 · 回撤 $2,000（EOD）· 日亏 $1,200（软性）· **手数上限 40 张微型**

## 第 2 步 · 免费 · TradersPost 连接

1. TradersPost 注册 → 连接 Lucid 账户
2. **先指向考核账户**（本来就是模拟盘）
3. 记下它给的 Webhook URL

---

## 第 3 步 · 免费 · 配置 alert

TradingView 脚本参数：

| 参数 | 值 |
|---|---|
| 执行桥接商 | `TradersPost` |
| Alert symbol | `MNQ1!` |
| 点值 | `2` |
| **手数上限** | **`40`**（Lucid $50K） |
| Arm live orders | **先保持关闭** |

创建警报：

1. 条件选**策略本身**（不是某个单独信号）
2. Webhook URL 填 TradersPost 给的
3. 消息填 `{{strategy.order.alert_message}}` — 脚本已按核实过的 schema 拼好

脚本发出的内容（示例值，已验证为合法 JSON）：

```json
{"ticker":"MNQ1!","action":"buy","sentiment":"bullish","quantity":2,"stopLoss":{"type":"stop","stopPrice":21160.25}}
{"ticker":"MNQ1!","action":"exit","sentiment":"flat"}
```

---

## 第 4 步 · 走 `paper_check.md`

打开 `Arm live orders`，按清单跑。**两条一票否决**：

1. **券商端能看到挂着的止损单**——这个策略全靠固定止损保护，桥接如果只转市价单你就是裸仓
2. **10 天方向 10/10 一致**——方向错是配置错误不是滑点

---

## 第 5 步 · 通过考核之后

这一步开始才是真钱。建议：

- 保持 $50K，不要急着升档
- `Stop after N consecutive losing days` 设 5
- 想放大：**先复制多个 $50K，不要开大档**。但注意复制账户完全正相关，一个爆全部爆，
  收入、手续费、爆仓风险同比例放大，一点分散都没有
