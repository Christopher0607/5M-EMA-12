# TopStep 落地指南

> 你说先不用 Lucid，用 TopStep。这份文档只讲 TopStep。
> Lucid 的路径在 `connect.md`，两份不要混着看——**桥接商和 JSON 格式完全不同**。

---

## 0. 先看这三个数字

在讲怎么做之前，先把最优配置的真实结果放在这里。这是 16.2 年的模拟，不是月收益。

| | 数值 |
|---|---|
| 16.2 年净到手 | **$39,525** |
| 折合每年 | **约 $2,440** |
| 第一笔提现出现在 | **第 4.05 年** |
| 有资金账户的时间占比 | **17.8%** |
| 考试通过率 | **31%**（平均买 4 次考试过 1 次） |

**82% 的时间你是在考试、或者在等着重买考试。** 这个策略不是一台每月发工资的机器，
它是一个长期正期望、但中间有多年空窗的东西。

而且样本外（walk-forward）检验的结论是：上面这些还要**再打约三分之一折扣**，
因为这些参数是在已知全部历史的前提下挑出来的。

如果你看完这三个数字还想做，下面是怎么做。

## 1. 买 $150K，不要买 $50K

这一点和我之前给 Lucid 的建议**正好相反**，所以必须讲清楚原因。

| 档位 | 16.2 年净到手 | 考试通过率 |
|---|---|---|
| TopStep $50K | $2,670 | 13.1% |
| TopStep $100K | $17,650 | 28.1% |
| **TopStep $150K** | **$39,525** | **31.0%** |

$150K 是 $50K 的 **14.8 倍**。

### 为什么差这么多

**考试的一致性规则（consistency rule）卡的是「单日最大盈利 ≤ 利润目标的 50%」。**

| 档位 | 利润目标 | 单日盈利上限 |
|---|---|---|
| $50K | $3,000 | **$1,500** |
| $150K | $9,000 | **$4,500** |

这个策略每天只开一笔、持仓 6 小时、不设止盈——**盈利天生就是一块一块的**，
经常一天就赚掉一大截。在 $50K 上，一个 $1,600 的好日子就把这次考试废了；
同样这一天在 $150K 上完全合规。

所以不是「大账户赚得多」这么简单——是**小账户的规则和这个策略的形状不兼容**。

### 手续费会不会翻盘

会问这个是对的：我的模型对三个档位都用了 $49 的考试费，而真实的 $150K 月费更贵
（大约 $149）。所以我把几种可能的收费方式都算了一遍：

| 收费假设 | $150K 净到手 |
|---|---|
| 模型原样（$49 / $49） | $39,525 |
| 考试 $149，资金账户月费 $49 | $35,148 |
| 考试 $149，资金账户月费 $149 | $31,694 |
| 考试 $149，资金账户免月费 | $36,840 |

**最差的情况也是 $31,694，还是 $50K（$2,670）的 12 倍。** 结论不受收费方式影响。

> 定价会变。付钱之前自己去 TopStep 官网核对当期价格和规则——本文的规则数据
> 是特定日期抓的，propfirm 改规则很频繁。

## 2. $150K Combine 的规则（这些会真的卡到你）

| 规则 | 数值 | 会怎么咬你 |
|---|---|---|
| 利润目标 | $9,000 | — |
| 追踪回撤 | $4,500 | 按**日终**结算移动，赚到 +$4,500 后锁在初始余额不再往上追 |
| **单日亏损上限** | **$3,000** | **硬性**。触发直接结束，不是警告 |
| 一致性规则 | 单日盈利 ≤ $4,500 | **卡的是「能不能通过」**，不是通过之后 |
| 最大手数 | 150 手微型 | 填错直接违规 |

资金账户阶段：

| 规则 | 数值 |
|---|---|
| 最少交易日 | 5 天 |
| 单日最低盈利（算作有效交易日） | $150 |
| 单笔提现上限 | $5,000 毛 |
| 分成 | 90 / 10 |

> 提现上限 $5,000 是**毛额**，你拿 90% = **$4,500**。模拟里 29 笔提现，
> 平均到手 $1,496，最大的那笔正好是 $4,500——也就是撞到了上限。

**Combine 本身是模拟盘。** 考试阶段亏的是虚拟钱，你真正付出的只有考试费。
真金白银只在拿到资金账户之后才涉及。所以「先跑模拟」和「买一个考试」几乎是同一件事。

## 3. 桥接商：PickMyTrade

TopStep 跑在 TopstepX / ProjectX 上，**TradersPost 不支持**，所以不能用 Lucid 那条路。
TradingView → TopStep 用 **PickMyTrade**。

脚本里「Execution bridge」参数已经默认选好 `PickMyTrade` 了。

### 最容易犯的错：符号写错

| 桥接商 | Alert symbol 要填 |
|---|---|
| PickMyTrade（TopStep） | **`MNQ`** ← 根代码 |
| TradersPost（Lucid） | `MNQ1!` |

**PickMyTrade 要根代码 `MNQ`，不是图表上的 `MNQ1!`。** 填成 `MNQ1!` 的话每一单都会被拒。
脚本的状态表会检查这一点：填错了「桥接商」那一行会显示 `⚠根代码`。

### token 和 account_id 是凭证

填进脚本参数之后，**必须把 TradingView 脚本设成 Private**。
公开发布的脚本会暴露 inputs——你的 token 就公开了。

留空也可以：脚本会自动省略这两个字段，你在 PickMyTrade 后台配置。**建议这样做。**

## 4. 脚本参数（$150K 用这套）

| 参数 | 值 | 说明 |
|---|---|---|
| Stop distance | `Percent of price` | |
| &nbsp;&nbsp;Percent (%) | `0.5` | 就是上面 $39,525 那个配置 |
| Position size | `Risk-based` | |
| &nbsp;&nbsp;Risk per trade ($) | `1500` | $150K 的 1% |
| Point value ($) | `2.0` | MNQ 微型 |
| **Max contracts** | **`150`** | **$150K 的上限，已是默认值** |
| Execution bridge | `PickMyTrade` | 默认 |
| Alert symbol | `MNQ` | 默认 |
| **Arm live orders** | **关闭** | **默认就是关的，别急着打开** |

图表必须是：**MNQ1! / 5 分钟 / 盘前盘后开启**（你已经开了）。

> 注意：图表符号是 `MNQ1!`，但 Alert symbol 参数填 `MNQ`。这两个是不同的东西——
> 一个是 TradingView 用来算行情的，一个是发给 PickMyTrade 的。

## 5. 安全阀（脚本内置，默认全开）

| 参数 | 默认 | 作用 |
|---|---|---|
| **Arm live orders** | **关** | 关的时候，**入场警报发出去的是一句不能解析的文本**，桥接商不会当成订单。回测和画图完全不受影响 |
| Limit to a date window | 关 | 限定生效日期，防止图表开着忘了关 |
| Stop after N consecutive losing trades | 0（关） | 连亏 N 笔后停止发单。平台的回撤规则会结束你的账户，这个先结束订单 |
| 重复入场防护 | 一直开 | 已有持仓时拒绝再次入场，挡掉桥接商重复投递同一条警报 |

**一个重要的设计决定：平仓警报即使在「未武装」状态下也是真的。**

原因：如果你在有持仓的时候把开关关掉，而平仓警报也被屏蔽了，那这个仓位就没人管了。
屏蔽入场是安全的，屏蔽出场是危险的。所以只屏蔽入场。

## 6. 步骤

### 第 0 步 · 免费 · 再核一次对账

脚本改过了（改的是警报格式和安全阀，**没碰信号逻辑**），理论上成交列表应该和你上次
核对的完全一样。扫一眼确认：

```bash
./.venv/bin/python scripts/export_tv_check.py --since 2025 --max-contracts 150
```

策略测试器的成交列表 vs `results/tv_expected_trades.csv`，对**日期 + 方向**。
方向必须 100% 一致；价格差几个跳是正常的。

### 第 1 步 · 免费 · PickMyTrade 注册 + 连 TopStep

1. PickMyTrade 注册，连上你的 TopStep 账户（**先连模拟账户**）
2. 后台拿 webhook URL
3. 记下 token 和 account_id（**不要填进脚本**，在后台配置）

### 第 2 步 · 免费 · Webhook 冒烟测试

按 `paper_check.md` 第 1 节走。目标是**不下真单**的情况下确认：

- 警报能到 PickMyTrade
- JSON 能被解析（脚本发的格式已经按官方文档核对过）
- 符号 `MNQ` 能被识别

### 第 3 步 · 约 $149 · 买 $150K Combine

Combine 是模拟盘，风险只有这笔费用。

打开 `Arm live orders` **之前**，先在模拟账户上走完 `paper_check.md` 的
**连续 10 个交易日**。两个硬性门槛：

| 检查项 | 通过标准 | 不过怎么办 |
|---|---|---|
| **方向** | **10/10 完全一致** | ❌ **立刻停**。这是配置错，不是滑点 |
| **止损单** | **10/10 在券商端真的存在** | ❌ **立刻停** |

第二条是最关键的一条：**这个策略全靠固定止损保护**。
如果 PickMyTrade 只发了市价单、没发止损单，那 $3,000 的单日亏损上限会在某一天
直接结束你的账户，而你到那天才会发现。

**去 TopStep 的持仓界面亲眼看到那张止损单。** 不要信任何一层的日志。

### 第 4 步 · 考试

预期：**中位数 5.1 个月通过，2.3 个月爆掉**。通过率 31%。
爆了就重买——模型里 16.2 年买了 44 次考试，过了 11 次。

考试期间盯一件事：**单日盈利不要超过 $4,500**。这是一致性规则，
超了不会立刻爆，但会卡住你的通过。

### 第 5 步 · 资金账户 · 什么时候提现

**用 `immediate`：只要超过安全线就全部提出来。**

模拟里三种提现策略的对比（$150K，0.5% 固定止损）：

| 提现策略 | 净到手 | 提现笔数 |
|---|---|---|
| **immediate（马上提）** | **$39,525** | 29 |
| accumulate（攒到 $2,000 再提） | $15,511 | 9 |
| half_buffer（提一半留一半） | $13,270 | 25 |

**马上提比攒着多 2.5 倍。**

原因是 TopStep 的追踪回撤：留在账户里的钱把回撤线往上顶，
顶上去之后一个回调就把你扫掉了——那些没提的利润就一起没了。
**账户里的钱不是你的，提出来的才是。**

唯一的例外是最开始：拿到资金账户后要先满足 5 个交易日、
每天至少 $150 盈利，才能第一次提现。

---

## 7. 什么时候该停

- 模拟盘方向对不上 → **立刻停**，回去查盘前盘后
- 券商端看不到止损单 → **立刻停**
- 连续亏损超过你能承受的考试费 → 停。把 `Stop after N consecutive losing trades` 设上
- 真实成交和 CSV 持续偏离（不是几个跳，是方向或笔数） → 停

---

## 8. 必须你自己做的事

1. **去 TopStep 官网核对当期规则和价格。** 本文的规则数据是特定日期抓的，
   propfirm 改规则很频繁，改了不会通知你。
2. **脚本设 Private**（如果你填了 token）。
3. **手数上限按你实际买的档位填。** 买了 $50K 却填 150，第一单就违规。
4. **不要多账户复制。** 回测显示复制账户完全正相关——一个爆，全部爆。
   要放大就买一个大的，不要买几个小的。

## 9. 一个没验证过的想法

数据里有一件事值得说，但**我没有验证过，所以不是建议**：

| $150K 配置 | 通过率 | 净到手 |
|---|---|---|
| `pct 0.5% 固定止损` | 31.0% | **$39,525** |
| `fixed N=1 移动止损` | **68.5%** | $12,838 |

通过率最高的配置，赚得最少；赚得最多的配置，通过率只有一半。

那能不能**用 N=1 移动止损去考试，通过之后换成 0.5% 固定止损去赚钱**？
听起来合理。但是：

- 我的模拟**全程只用一个配置**，没有模拟中途切换，所以这个组合的收益我不知道
- N=1 那条路通过慢得多（8.5 个月 vs 5.1 个月），月费会吃掉一部分优势

**在我实际跑过之前，这只是一个假设。** 想试的话告诉我，我可以把切换逻辑加进模拟里再算一遍。

## 附：警报设置

1. TradingView → 脚本上点「创建警报」
2. 条件选**策略本身**（`NQ 5m EMA12 Open`），不是某个单独信号
3. Webhook URL 填 PickMyTrade 给的地址
4. 消息内容填：

```
{{strategy.order.alert_message}}
```

就这一行。JSON 是脚本按 PickMyTrade 官方格式拼好的，**不要手改**。

脚本实际发出去的内容（`Arm live orders` 打开后）：

```json
{"symbol":"MNQ","data":"buy","quantity":3,"sl":21160.25}
{"symbol":"MNQ","data":"sell","quantity":3,"sl":21360.75}
{"symbol":"MNQ","data":"close"}
```

这三种格式在 `tests/test_pine_payload.py` 里逐个解析验证过——
测试直接读取脚本源码来拼，所以脚本改了测试会跟着变，不会对不上。
